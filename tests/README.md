# Автотесты Traffic Simulation


# ONLY FOR LINUX RUNNING
Полный набор автоматизированных тестов для проекта Traffic Simulation, включающий модульные, интеграционные и функциональные тесты.

## 📁 Структура тестов

```
tests/
├── __init__.py                 # Пакет тестов
├── conftest.py                # Конфигурация pytest и фикстуры  
├── test_entities.py           # Тесты сущностей (Vehicle, Car, Pedestrian)
├── test_traffic_controller.py # Тесты контроллера трафика
├── test_simulation.py         # Тесты основной симуляции
├── test_utils.py              # Тесты вспомогательных функций
├── test_integration.py        # Интеграционные тесты
├── test_runner.py             # Кастомный запускальщик тестов
└── README.md                  # Эта документация
```

## 🚀 Запуск тестов

### Быстрый старт

```bash
# Все тесты
python run_tests.py

# Только быстрые тесты (без интеграционных)
python run_tests.py --fast

# С анализом покрытия кода
python run_tests.py --coverage

# С HTML отчетом
python run_tests.py --html-report
```

### Использование pytest (рекомендуется)

```bash
# Все тесты
pytest tests/

# Только модульные тесты
pytest -m unit

# Только интеграционные тесты  
pytest -m integration

# С покрытием кода
pytest --cov=. --cov-report=html

# Подробный вывод
pytest -v -s
```

### Использование unittest

```bash
# Все тесты
python -m unittest discover -s tests -p "test_*.py" -v

# Конкретный модуль
python -m unittest tests.test_entities -v

# Конкретный тест
python -m unittest tests.test_entities.TestVehicle.test_vehicle_initialization -v
```

### Кастомный test runner

```bash
# Все тесты
python tests/test_runner.py

# Только модульные тесты
python tests/test_runner.py --unit

# Только интеграционные тесты
python tests/test_runner.py --integration

# С подробным выводом
python tests/test_runner.py --verbose
```

## 📋 Категории тестов

### 🔧 Модульные тесты (Unit Tests)

Тестируют отдельные компоненты в изоляции:

- **test_entities.py**: Тесты классов Vehicle, Car, Pedestrian
- **test_traffic_controller.py**: Тесты системы светофоров
- **test_utils.py**: Тесты вспомогательных функций

### 🔄 Интеграционные тесты (Integration Tests)

Тестируют взаимодействие между компонентами:

- **test_integration.py**: Тесты полного цикла симуляции, взаимодействия объектов
- **test_simulation.py**: Тесты основного класса симуляции

### 🏷️ Маркировка тестов

Тесты помечены специальными маркерами для удобной фильтрации:

- `@pytest.mark.unit` - Модульные тесты
- `@pytest.mark.integration` - Интеграционные тесты
- `@pytest.mark.simulation` - Тесты симуляции
- `@pytest.mark.slow` - Медленные тесты

## 🔍 Что тестируется

### Сущности (Entities)

#### Vehicle
- ✅ Инициализация с корректными параметрами
- ✅ Установка целевой полосы в зависимости от направления поворота
- ✅ Правильность начальной позиции для разных направлений
- ✅ Нормализация векторов направления движения

#### Car (Автомобили)
- ✅ Корректная инициализация всех свойств
- ✅ Генерация неоновых цветов для визуализации
- ✅ Физика движения и обновление позиции
- ✅ Система обнаружения столкновений
- ✅ Логика поворотов на перекрестке
- ✅ Регулировка скорости и смена полос

#### Pedestrian (Пешеходы)
- ✅ Инициализация с начальной и целевой позицией
- ✅ Алгоритм движения к цели
- ✅ Обнаружение достижения цели
- ✅ Система избегания столкновений с машинами
- ✅ Групповое поведение пешеходов

### Контроллер трафика

#### TrafficLight (Светофоры)
- ✅ Инициализация вертикальных и горизонтальных светофоров
- ✅ Корректная смена цветов (красный/желтый/зеленый)
- ✅ Активация соответствующих линз

#### TrafficController (Управление)
- ✅ Статический режим с фиксированными фазами
- ✅ Динамический режим с адаптацией к трафику
- ✅ Расчет давления трафика по направлениям
- ✅ Безопасные переходы между фазами
- ✅ Расчет времени ожидания транспорта

### Симуляция

#### TrafficSimulation
- ✅ Инициализация всех компонентов
- ✅ Спавн и удаление машин и пешеходов
- ✅ Обновление таймеров и состояний
- ✅ Сбор и предоставление статистики
- ✅ Загрузка и применение конфигурации
- ✅ Сброс состояния симуляции

### Вспомогательные функции

#### Отрисовка
- ✅ Корректная отрисовка дорог с разным количеством полос
- ✅ Отрисовка пешеходных переходов

- ✅ Математические расчеты (расстояние, углы, векторы)
- ✅ Проверка столкновений и пересечений
- ✅ Валидация цветов и генерация неоновых эффектов

- ✅ Поведение пешеходов при красном/зеленом свете

## 🐛 Отладка тестов

### Подробный вывод
```bash
pytest -v -s  # -v подробно, -s показывает print
```

### Запуск конкретного теста
```bash
pytest tests/test_entities.py::TestVehicle::test_vehicle_initialization -v
```

### Остановка на первой ошибке
```bash
pytest -x  # Остановиться на первой ошибке
pytest --maxfail=3  # Остановиться после 3 ошибок
```

### Повторный запуск упавших тестов
```bash
pytest --lf  # Last failed
pytest --ff  # Failed first
```

## 🔍 Рекомендации по тестированию

### При добавлении новых функций
1. Напишите тест до реализации (TDD)
2. Убедитесь, что все граничные случаи покрыты
3. Проверьте взаимодействие с существующими компонентами

### Поддержка качества
1. Регулярно запускайте полный набор тестов
2. Поддерживайте покрытие кода выше 80%
3. Обновляйте тесты при изменении функциональности

### Производительность
1. Помечайте медленные тесты маркером `@pytest.mark.slow`
2. Используйте фикстуры для переиспользования объектов
3. Избегайте реальных сетевых запросов и файловых операций
