# Traffic Intersection Simulation

Интеллектуальная система симуляции перекрестка с адаптивным управлением светофорами и интеграцией ИИ.

## Описание проекта

Это продвинутая симуляция городского перекрестка, разработанная на Python с использованием pygame. Система включает в себя реалистичное моделирование трафика, пешеходов и интеллектуальное управление светофорами с возможностью генерации сценариев при помощи ИИ.

### Ключевые особенности

#### 🚗 Реалистичная модель транспорта
- **Интеллектуальные автомобили** с индивидуальными характеристиками (размер, ускорение, торможение)
- **Адаптивное перестроение** между полосами при необходимости
- **Плавные повороты** на перекрестке с физически корректной траекторией
- **Система безопасной дистанции** с динамической адаптацией скорости
- **Разнообразие типов ТС**: легковые, средние и крупные автомобили

#### 🚦 Интеллектуальное управление светофорами
- **Статический режим**: классические фиксированные фазы
- **Динамический режим**: адаптивная система с машинным обучением
  - Дифференциальные уравнения для моделирования давления трафика
  - Взвешенная система штрафов за время ожидания
  - Автоматическая оптимизация длительности фаз

#### 🚶 Система пешеходов
- **Реалистичное поведение**: пешеходы ждут красного света для всех направлений
- **Неоновая визуализация** в киберпанк стиле
- **Автоматическое управление потоком** с динамическим спавном

#### 🤖 ИИ-генерация сценариев
- **Интеграция с LLM** (LM Studio) для автоматической настройки
- **Естественно-языковые команды**: описываете сценарий словами
- **Валидация конфигураций** с JSON Schema
- **Примеры сценариев**: "Вечерний час пик, пробка с запада"

#### 🎨 Визуальный стиль
- **Киберпанк/неон эстетика** с динамическим свечением
- **Адаптивный интерфейс** с прокруткой и интерактивными элементами
- **Звездное небо** и атмосферные эффекты
